# BlockBid: Smart Estimating With Videogames

Estimating a construction project is slow, expensive and opaque, especially for first-time owners and newcomers to the industry.
BlockBid turns sandbox games like Minecraft into an intuitive 3D estimating interface. Users build a structure in a familiar game; our AI converts the build into a quantity takeoff, maps each element to real-world materials and assemblies, applies regional unit costs and labor productivity rates, and returns an itemized conceptual estimate with plain-English explanations. 
Users can ask the AI assistant "what-if" questions ("what if we use steel framing?") and see cost updates instantly. The same approach can produce replacement-cost estimates for existing buildings by modeling them in-game.
BlockBid makes early-stage budgeting accessible to anyone who can play a game.
